## 🌟 About

**Tic Tac Toe** is a lightweight, browser-based two-player game built with pure **HTML, CSS and JavaScript** — no frameworks, no installs, no fuss. Open the link, pick a square, and challenge a friend in seconds.

> 🔗 **Play it now → https://muneeb-fayaz.github.io/tic-tac-toe/**

---

## 🎯 Features

| | Feature | Description |
|---|---|---|
| 👥 | **Two-Player Mode** | Player **X** and Player **O** take turns on the same device |
| 🔔 | **Turn Indicator** | Always know whose move it is — *"Player X's turn"* |
| 🏆 | **Live Scoreboard** | Wins tracked for both players across rounds |
| 🔄 | **Reset Game** | Start a fresh board with a single click |
| 📱 | **Responsive Layout** | Plays smoothly on desktop, tablet and mobile |
| ⚡ | **Zero Dependencies** | Pure vanilla web tech — loads instantly |

## 🕹️ How to Play

1. 🌐 Open the **[live game](https://muneeb-fayaz.github.io/tic-tac-toe/)**.
2. ✕ **Player X** always goes first — click any empty square.
3. ○ **Player O** plays next. Keep alternating turns.
4. 🏁 Get **three in a row** — horizontally, vertically or diagonally — to win.
5. 🤝 If all nine squares fill up with no winner, it's a **draw**.
6. 🔄 Hit **Reset Game** to play another round.

### 🧩 Winning Combinations

```
Rows:       [0,1,2]  [3,4,5]  [6,7,8]
Columns:    [0,3,6]  [1,4,7]  [2,5,8]
Diagonals:  [0,4,8]  [2,4,6]
```
